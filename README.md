# CareerCue — Downloads

Installers for **CareerCue — Interview AI Assistant**: a desktop app that
listens to your interview, works out what you have been asked, and puts a clear
answer on your screen.

**[Download the latest release](../../releases/latest)** · **[Installation guide](https://runtym.com/interview-ai-assistant)**

| File | For |
|---|---|
| `CareerCue-<version>-arm64.dmg` | macOS — Apple Silicon (M1–M5) |
| `CareerCue-<version>.dmg` | macOS — Intel |
| `CareerCue-Setup-<version>.exe` | Windows 10 / 11, 64-bit |
| `ai-interview-assistant_<version>_amd64.deb` | Debian, Ubuntu, Mint, Pop!_OS |
| `CareerCue-<version>.AppImage` | Any other 64-bit Linux |

Not sure which Mac build you need? Apple menu → **About This Mac** → look at
**Chip**. Apple M-series means Apple Silicon; anything saying Intel means Intel.

macOS shows a caution the first time you open the app, because it is not yet
notarised by Apple. The [installation guide](https://runtym.com/interview-ai-assistant)
explains how to allow it — it is a one-time step.

`SHA256SUMS.txt` on each release lets you verify a download completed intact.
